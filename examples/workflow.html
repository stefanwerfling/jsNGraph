jsNGraph Overview Board editor Workflow
Drag from an output port to an input port.
Drag onto the canvas
drag from the palette (onto a connection to insert) · double-click a note or connection to write
drag ports to connect · drag a connected input to move it · “+” adds a node
Shift+drag: select area · Del: delete (re-links the chain) · D: disable
Ctrl+G: group into a sub-workflow · Ctrl+Shift+G: ungroup · double-click a collapsed group to open it
Ctrl+C / X / V / D: copy, cut, paste, duplicate · Ctrl+Z / Ctrl+Y · wheel: zoom
